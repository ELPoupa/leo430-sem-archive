MACRO Pump (Version 2)
  Comment  Used for Default Toolbar-Macro Sample Change Toggle
  Comment  Starts Pumping, Displays Vac Status,at Vac Ready, Hide Vac Status, Restore Beam.
  Command  CMD_PUMP
  Panel  0%1%3
  WaitForTimeout  DP_VACSTATUS%1%2000
  Panel  1%1%3
  IfThen  DP_RUNUPSTATE%1%1
    IfThen  DP_RUNUPSTATE%10%0
      Command  CMD_BEAM_ON
    EndIf
    IfThen  DP_RUNUPSTATE%0%0
      Command  CMD_MANUAL
    EndIf
    WaitForTimeout  DP_RUNUPSTATE%1%60
  EndIf

MACRO VENT (Version 2)
  Comment  Used for Default Toolbar-Macro Sample Change Toggle
  Comment  Ensures system is safe to VENT and then VENTS. 
  Comment  Ensure EHT is off
  IfThen  DP_RUNUPSTATE%0%1
    IfThen  DP_RUNUPSTATE%10%1
      Command  CMD_EHT_OFF
      WaitForTimeout  DP_RUNUPSTATE%10%60
    EndIf
  EndIf
  Comment  Ensure stage is initialised
  IfThen  DP_STAGE_MOTOR%1%0
    IfThen  DP_STAGE_INIT%0%0
      Message  %#DP_FLAG0Stage is NOT initialized and may not allow safe operation. Do you want to initialize now?
      IfThen  DP_FLAG0%1%0
        Command  CMD_STAGE_INIT
      Else
        Halt
      EndIf
    EndIf
    Comment  move stage to safe position
    Analogue  AP_STAGE_GOTO_Z%1.000000e-003
    WaitForTimeout  DP_STAGE_IS%0%60
    Analogue  AP_STAGE_GOTO_X%5.000000e-002
    WaitForTimeout  DP_STAGE_IS%0%60
    Analogue  AP_STAGE_GOTO_Y%5.000000e-002
    WaitForTimeout  DP_STAGE_IS%0%60
  EndIf
  Comment  and finally vent
  Comment  Flag 0 indicates if sequence OK (=0) or to be aborted (=1)
  Digital  DP_FLAG0%1
  While  DP_FLAG0%0%1
    IfThen  DP_VENT_INVALID_REASON%0%0
      Command  CMD_VENT
      Digital  DP_FLAG0%0
      Halt
    Else
      Comment  Wait until valid or aborted
      Panel  0%0%3
      Message  %#DP_FLAG1Venting is inhibited. See Vacuum tab for reason. Remove cause of inhibit and press YES to try again or press NO to abort  
      IfThen  DP_FLAG1%0%0
        Halt
      EndIf
    EndIf
  EndWhile
