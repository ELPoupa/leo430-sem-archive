$#>Define your own Bitmaps
Each of the bitmap images provided as standard has a number in the range 1 through 52
Example: Icon 1 is the restore Icon {bmc bm22.bmp} 
To determine the icon numbers in your current toolbar select context help mode <Shift + F1> and then click on an icon.

When a toolbar is loaded (on User Interface Start or load/edit in the toolbar editor) the software searches for an icon file and, if it finds it, loads it in place of the standard icon bitmap. (Note, once a replacement bitmap is loaded it will only revert to the standard on restarting the UIF after the file(s) have been deleted).

If the common ToolbarCommon_Toolbar property is not set for the user the search locations are:
1.	In the user directory
2.	In the Distribution directory (..\leo32\distrib)

If the common toolbar property is set the search location is:
{bmc bm2.bmp}	..\leo32\user
The bitmaps will be used even if a common toolbar is not present

Toolbar Icon Files have a standard name format which is TOOLn.BMP

To Create an Icon Bitmap file:
{bmc bm2.bmp}	Use MS Paint (Start-programs-accessories-paint)
{bmc bm2.bmp}	Set the Image attributes to 32 pixels wide and 31 pixels high
{bmc bm2.bmp}	Tip - use View-zoom-large size
{bmc bm2.bmp}	Design your bitmap
{bmc bm2.bmp}	SaveAs TOOLn.BMP and must be 16 colour bitmap format
