$#>KStore / Recall

A list of stage positions may be maintained in memory. The entries are shown in the Stage Points List. Initially this list is empty. The data saved is the current position of the stage. If beam shift is being applied the XY stage position is modified by the Beam Offset distance to give a stage XY position with zero beam shift. Also saved are the current working distance and magnification. When moving to a stored position the beam shift is set to zero and optionally either or both of the magnification/working distance are set to the saved values.

$#>Touch Alarm
If the stage touches the chamber, detectors etc an audible warning and on-screen message is given. 
Movement is stopped and is only possible in the reverse direction until the alarm is cleared.

It is advisable to use protected ZK8LPPZ@tabmgr.hlp mode to minimise the risk of a touch.

Note: When the stage is near the $Exchange_Exchange position the touch alarm is disabled.
