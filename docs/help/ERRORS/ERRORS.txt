$#Stage Limits

The motorised stage has six limits per axis:

Low Outer
Low Inner
Low User

Normal working range

High User
High Inner
High Outer
.
The user limits are defined by the user, by default they are set at the outer limits.

If an inner limit is detected the stage slows down and does not lose position.
If an outer limit is detected the stage stops immediately and position is lost.
Note that an outer limit should not be detected except in hardware error conditions (e.g. dirty track/contact on stage limit PCB failing to detect inner limit).

$Stage Limits

The motorised stage has six limits per axis:

Low Outer
Low Inner
Low User

Normal working range

High User
High Inner
High Outer
.
The user limits are defined by the user, by default they are set at the outer limits.

If an inner limit is detected the stage slows down and does not lose position.
If an outer limit is detected the stage stops immediately and position is lost.
Note that an outer limit should not be detected except in hardware error conditions (e.g. dirty track/contact on stage limit PCB failing to detect inner limit).
