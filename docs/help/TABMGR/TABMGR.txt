$#Protected Z

This SEM parameter controls the behaviour of the stage when a multi axis move is performed (e.g. Go To a position label).

Parameter not Set.
All relevent axes move simultaneously to the desired position.
Backlash correction performed if required.

Parameter Set
The move to the desired position is performed in phases to minimise the risk of collision.
The parameter Safe Z defines the maximum Z position to be used while moving in XY. Set this according to the tallest sample you have mounted.

The movement sequence is:

If either the desired Z or Safe Z is lower than the current Z then this axis is moved to whichever is the lowest position.
If the desired Tilt is lower than the current Tilt then this axis is moved to the desired position
The X,Y,R,M axes are moved simultaneously to their desired positions
If The desired Tilt position is not yet achieved move Tilt to the desired position
If the desired Z position is not yet achieved move Z to the desired position.


The Protected Z parameter may only be changed with Supervisor PrivilegeXTAC5O@admin32.hlp.

$#>X-Ray Dot Map: Element Priority

In this mode X-Ray counts are accumulated on each X-Ray port (energy window) for each pixel. If the count is non zero then the associated bit in the image store pixel is set, making a pixel DOT of the selected colour.

When a pixel contains non zero counts on two or more ports (energy windows) then the one displayed is determined by the presence priority which may be altered as required.

The Element Priority window is a box containing all the identities of the data sources. This window determines the priority of the presence dot when two or more occur in the same pixel. The top of the box is the highest priority. 

{bmc bm1.bmp} The priority may be changed by selecting an entry with the mouse and the moving it with the buttons Move Up and Move Down to the required priority position.

{bmc bm4.bmp} Once the data has been collected the priority may be rearranged interactively to see the effect on the display. This is non destructive to the X-Ray data.

$#>SEM Control Signal
This tab provides the Auto signal level functions
Brightness and contrast can also be controlled directly from this panel using the slider bars labelled accordingly.  There are two types of auto signal level function which each operate in two ways. The auto signal level function will either control the Mean signal level or the Peak signal level. The mean signal level is defined as being the average brightness of all the pixels in the image, while the peak level is defined as the brightness of the brightest part of the image.  Peak and mean signal level controls each operate in two ways. The Find function is a single shot activation which sets the peak or mean to the level defined in the associated Auto Video slider bar. The Keep function activates the auto video function to maintain the video level (peak or mean) of the image at the time of selection. Typically the Find function will be used to set the required video level if the image is a long way from the required brightness. The Keep function is useful when the content of the image is likely to change, for example if the stage is being moved across a specimen with distinct light and dark phases, or if the probe current is being adjusted. Auto video control can be disabled at any time by selecting the  Off buttons.	{bmc bm31.bmp}

$#>Frame Average Mode

When frame average is selected the live signal is proportionally mixed with the store signal so that the image reflects the average of the recent frames. 

 The proportion of live to stored can be adjusted with the parameter N which represents the number of frames to be averaged. 

 Frame average can be selected with any scan speedscan_speed , but is generally most useful at the faster speeds  where a larger amount of noise reduction can be obtained without introducing a long cycle time.

There is one important difference between line and frame average. In line average mode the same noise reduction is applied to all the active zones. But for frame average it is possible to set different frame counts for each zone.
$#>Line Average Mode

Selecting the line average causes each line to be scanned a number of times before the scan moves on.  The average line signal is stored and displayed.

The Noise reduction parameter N defines the number of times a line is to be averaged before moving to the next line

Line average is used when the result of the noise reduction needs to be seen without waiting for the cycle to complete.  

There is one important difference between line and frame average. In line average mode the same noise reduction is applied to all the active zones. But for frame average it is possible to set different frame counts for each zone.

$#>Filament Saturation
The setting of the filament current will have a large effect on the brightness and stability of the image, as well as influencing the lifetime of the filament. As the filament current is increased the brightness of the signal increases until a small plateau is reached, this is known as the "first peak" (see Figure), increasing the filament further will again cause the signal brightness to increase until another plateau is reached, further increase of the filament current will not improve the signal brightness, this is referred to as the fully saturated condition. The lifetime of the filament decreases as the filament current increases, there is no advantage in increasing the filament current above the just saturated condition. 

{bmc bm33.wmf}
The filament should be operated at one of two conditions, either at the first peak setting or where the filament has become just fully saturated.  These two positions will provide conditions for stable brightness operation. Operating at the first peak setting will give a long filament life, but is not satisfactory for high resolution imaging, while the fully saturated condition will give the brightest signal and allow the best resolution images to be obtained, but the lifetime of the filament will be reduced.

The filament current may be varied by using the associated scroll bar within the SEM Control GunSEM_Control_Gun tab, either by SLOWLY dragging the slider in the appropriate direction, or by clicking over the arrow at the appropriate end of the scroll bar while observing the points at which maximum brightness occurs.  The two peaks of maximum brightness correspond to the two saturation peaks.

This procedure should be carried out in conjunction with Beam AlignmentBeam_Alignment  if the optimum settings are to be achieved
$#>Beam Alignment
The beam is correctly aligned down the column when the brightness level of the signal cannot be increased any further (ensuring the system is switched to MANUAL brightness control) by any adjustment of the gun align screws.  These are moved as opposite pairs where one is slackened and the other screwed in.  Both pairs should be adjusted against each other until the signal brightness is at a maximum.  This adjustment should be carried out in conjunction with the filament current adjustmentFilament_Saturation, if the optimum settings are to be achieved.
$#>KOptibeam
The Optibeam program takes the requirements for probe current, working distance, etc. and determines the optimum lens settings to achieve the best performance from the column. Usually the best performance is defined as the highest resolution, but Optibeam can be set to other modes as described below.

Optibeam On
If enabled Optibeam is On, which means that the lens currents will be calculated to give the best performance after each change to the operating conditions. When disabled the lenses can be controlled manually. The instrument is normally operated with Optibeam On.

Optibeam Depth Mode
If this is enabled Optibeam automatically adjusts the lenses to obtain the largest depth of field for the operating conditions being used. If disabled, Optibeam automatically adjusts the lenses for optimum resolution performance for the prevailing operating conditions.

Optibeam Auto Resolution Mode 
If this is selected Optibeam automatically controls the probe current115R0I@operation.hlp (I Probe) to give operating conditions consistent with the magnification so that the resolution is not compromised by the spot size being too large.

Optibeam Conjugate mode
This is a special mode used when Electrostatic Beam Blanking is fitted. For operation see the EBBU documentation



Depth mode is not available in conjugate mode.
