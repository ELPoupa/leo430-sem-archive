$#Macro Library
A Macro Library is a collection of macros held in memory ready for execution.
The macro library is loaded from a library file (.MLL) in the User Directory.

When macros are deleted or saved in memory the Library file is also updated.

If the User Directory is changed the Macro Library is loaded from the File in the new User D|irectory and any currently executing macros are terminated.

If the User Directory does not contain a macro library file then a new one is created (CURRENT.MLL) from a Standard Macro Library in ..\Leo32\Distrib\Default.MLL

The Standard Macro Library contains all the Standard Macros required,  for the Standard Toolbar etc.

All macro libraries must contain these standard macros. This may be achieved either by Loading the Standard Library (Library-Load Standard Library) or by merging the Standard Library with the current Library (Library-Merge Standard Library)

$#Macros - Overview
A macro is a sequence of Macro Instructions which are executed on user request to achieve a specific result.  Each macro is identified by a macro name.

Macros are collected together into a Macro Library from which they may be executed.

There is a macro Library per User Directory. Changing to a different User Directory changes to a different Macro Library. Note that any executing macros are aborted on change of macro library.

If a Macro Library does not exist when a User Directory is selected a Default Macro Library is loaded.

Macro execution may be initiated from the User Interface, Special Function keys, Macro buttons on dialogs, Toolbar Icons and by the Macro Editor.

Any number of macros may run simultaneously, however only one copy of a macro may be executed at a time. Attempting to run a macro which is already executing will result in a Beep

One use of a macro is to restore machine conditions. This is achieved by a macro generator which is invoked either on shutdown when the user requests save conditions or by requesting save stateI6NCK5@sem.hlp this inspects the current machine conditions and generates a macro to re-establish them.
The conditions are therefore achieved by loading and executing the saved macro from file.

Macros may be created or edited using the Macro editorMacro_Editor 

See also Macro - ContentsContents

$#Search Order for macro execution
When a macro is requested for execution the Macro Engine first tries to locate the macro in the current macro Library.

If the macro is not found in the libary it will try to execute it as a macro file MacroName.MLF in the current User Directory.

If this also fails it will then try to execute a macro file  ...\LEO32\User\MacroName.MLF

If this also fails it will try to execute a macro file  ...\LEO32\Distrib\MacroName.MLF.

A number of standard macros are located in the Distribution directory.
To override them create new macros in the macro library or macro files in the \USER directory.

See Customising Default FilesCustomising_default_files and Macro LocationsMacro_Locations

$#Instruction Timeout
If an attempt is made to set a digital parameterSet_Digital_State, set an Analogue parameter Set_Analogue_Parameteror execute a commandExecute_Command which is disabled then the instruction is repeatedly executed without stepping on to the next instruction.

If after a timeout period the instruction still cannot proceed a message box is displayed notifying the user.

The user may choose:
{bmc bm0.bmp}	To stop the Macro
{bmc bm0.bmp}	To skip the instruction
{bmc bm0.bmp}	To wait a further timeout period

The default timeout period is 10 seconds.
The period may be changed from the menu using Edit - timeout.
