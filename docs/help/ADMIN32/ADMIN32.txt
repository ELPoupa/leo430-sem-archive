$#Licence validation
The installed licences are held in the leo database as a master copy.
Licences are valid only for a specific instrument Serial Number.
On Server Start up Serial Number checks are performed and if successful the licences are transferred to the Server which is their normal working location.
If the validation checks fail a failure message is displayed in the Server Window and the Server does not receive any licences, even those which are standard of the specific model of SEM.

$#Protected Z

This SEM parameter controls the behaviour of the stage when a multi axis move is performed (e.g. Go To a position label).

Parameter not Set.
All relevent axis move simultaneously to the desired position.
Backlash correction performed if required.

Parameter Set
The move to the desired position is performed in phases to minimise the risk of collision. 


The movement sequence is:


If the desired Z is lower than the current Z then this axis is moved to the desired position.
If the desired Tilt is lower than the current Tilt then this axis is moved to the desired position
The X,Y,R,M axes are moved simultaneously to their desired positions
If The desired Tilt position is not yet achieved move Tilt to the desired position
If the desired Z position is not yet achieved move Z to the desired position.


This Protected Z parameter may only be changed with Supervisor Privilege3CNN77.
$#Repair Accounting Database
This function is part of User AccountingUser_Accounting

This function attempts to repair a database that was marked as possibly corrupt by an incomplete write operation. This can occur if an application using the  database is closed unexpectedly because of a power outage or computer hardware problem. 

This function also attempts to validate all system tables and all indexes. Any data that can't be repaired is discarded. If the database can't be repaired, an error occurs.

When you attempt to open or compact a corrupted database, an error usually occurs. In some situations, however, a corrupted database may not be detected, and no error occurs. It's a good idea to use this function if the database behaves unpredictably.

Note   After repairing a database, it's also a good idea to compactCompact_Accounting_Database it  to defragment the file and to recover disk space.
