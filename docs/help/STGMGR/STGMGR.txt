$#Protected Z

This SEM parameter controls the behaviour of the stage when a multi axis move is performed (e.g. Go To a position label).

Parameter not Set.
All relevent axes move simultaneously to the desired position.
Backlash correction performed if required.

Parameter Set
The move to the desired position is performed in phases to minimise the risk of collision.
The parameter Safe Z defines the maximum Z position to be used while moving in XY. Set this according to the tallest sample you have mounted.

The movement sequence is:

If either the desired Z or Safe Z is lower than the current Z then this axis is moved to whichever is the lowest position.
If the desired Tilt is lower than the current Tilt then this axis is moved to the desired position
The X,Y,R,M axes are moved simultaneously to their desired positions
If The desired Tilt position is not yet achieved move Tilt to the desired position
If the desired Z position is not yet achieved move Z to the desired position.

The Protected Z parameter may only be changed with Supervisor PrivilegeXTAC5O@admin32.hlp.

$#>Survey Overview
Survey Mode provides the facility to enter a defined state [Survey Mode StateSurvey_Mode_State] (typically a long Working Distance and low magnification to achieve a wide field of view) in which the Specimen may be reviewed for features of interest.

While in Survey Mode State if a Centre PointN9YIPC@stage.hlp function is executed the software, in addition to moving the selected point to centre screen, switches to another defined state [Resolution Mode stateResolution_Mode_State] (typically a short working distance and higher magnification for better resolution) for examination of the point of interest.

Similarly if a Centre FeatureT2YJNK@stage.hlp function is executed while in Survey Mode State the software, in addition to moving the area selected to the centre of the screen and increasing magnification to fill the image, switches to Resolution Mode state.

If in Resolution State the Key <F4> will return to Survey Mode state.

Switching off Survey Mode returns to the conditions which existed when Survey Mode was switched On.

To set up conditions for Survey Mode State and Resolution Mode State display the Stage Manager Survey tabStgMgr_Survey from the Interface Main Menu Stage - Survey Mode - Settings or directly from the Stage Manager Control panel
