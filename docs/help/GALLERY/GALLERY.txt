This function deletes the selected image file.
$#Filename filter

The files displayed in the gallery are subjected to a filename filter, default *.TIF

You may modify this using the Menu function File - Filter, which displays the filter dialog.

Use the wildcards * and ? to define the required filter.
e.g. File??? or File*

Note: The extension  .TIF. is always added to the filter you supply.
$#Gallery File
A Gallery file is a cache of thumbnail images18H9TRS.
When the Gallery is opened the program attempts to open a gallery file Gallery.Gal in the image directory.
The Gallery file may not be present for two reasons:
1. This is the first time the Image Gallery has been used. A Gallery file will be created when the Gallery is closed.
2. The Image Directory may be read only (e.g. it may be on a CD-ROM). If this is the case a Gallery file may have been created in the User Directory.

If images have been created/Deleted since the Gallery was opened refreshRefresh the display.

$#Printing multiple images
The menu function File - Print will print the currently selected images (from 1 to 6 images) to the default printer.

All the images are printed on the same page.

The size and layout of the images depends on the number of images selected. All images are normalised to the same size such that they fit a single page in Landscape/Portrait.

Note that each image printed is a spatially reduced version of the TIFF file, there are no changes to magnification values to reflect the actual printed image size.

$#Refresh
This menu function (File - Refresh) of the Image gallery refreshes the Gallery fileGallery_File by comparing it's contents with the image directory.
Any files which have been deleted are removed and any files which have changed are replaced with new thumbnails18H9TRS.

$#Thumbnail 
A Thumbnail representation of an image is the image file spatially reduced to fit within a 128 * 96 pixel area for display in the Gallery.
The file name is displayed below the thumbnail.
$#KDrag and Drop
Files in the Image Gallery may be dragged and dropped onto other Windows, including those of other applications. See Drag and DropDrag_and_Drop@sem.hlp.

To drag an image select the Thumbnail required by holding the left mouse button down on it and drag it to its destination (e.g. The SEM Image Window)  then release the mouse button. The image will be loaded to the image store.

Other Drop targets are the Second Image Window4AHWGBN@tabmgr.hlp, Microsoft Word document windows and Windows Explorer (Directory).

Note: if dropping into the Explorer the files will be Moved, unless the <Ctrl> Key is held down before the drop.
Note: If Multiple files are to be dragged then drag the last selected thumbnail.
