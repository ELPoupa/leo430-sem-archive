$#>LUT Editor File Types

There are 3 different types of file associated with the LUT Editor. 

There are two formats for the Display LUT and one format for the Input LUT:

Input LUT Files (.ULU)

	Input LUT files have the extension .ULU. The current working file will be called CURRENT.ULU. Files saved in this format can only be used when the LUT Editor is in Input LUT mode.

Display LUT Files (.OLT, .DLU)

	The reason for the display LUT having two file formats is that if the user wishes to load in a special user defined LUT, then the definition for the LUT can be saved in ASCII format and edited by the user in a text editor such as Notepad.

	.OLT files are in a binary format and cannot be modified by the user.

	.DLU files are in ASCII format and can be modified by the user. See Sample .DLU FileSample_.DLU_File

$#>KWhat is the LUT Editor

The LEO-32 LUT Editor is a pop-up application or applet that allows the SEM operator to modify either the Input or Display Look Up Tables1QUPBH3@Sem.HLP (LUTs). These LUTs allow the user to highlight specific areas of interest on the specimen by modifying the colour values (grey values only for Input LUTs) used to represent the stored image data.

Both the input and display LUTs are described as a set of points that define the profile of the selected LUT in graphical format. The X-axis of a LUT represents the LUT colour entry in ascending order. The Y-axis of the LUT represents the intensity of the colour entry from minimum to maximum.

As each LUT is described by a set of points, the lines between adjacent points define a gradient of intensity for the range of LUT entries between these adjacent points. Thus for a linear LUT, it is only necessary to have two points one at (Xmin,Ymin) and the other at (Xmax, Ymax), which define a 1:1 mapping between LUT entries and intensity.

The LUT Editor is controlled mainly by a simple 'selection and execution' process using the mouse. The user 'selects' a toolbar function and 'executes' its features by clickingCLICK@Sem.HLP and draggingDRAG@Sem.HLP the LUT points.

All changes with the exception of the Step LUT function that are made to the Input or Display LUTs are applied immediately to the image store. After each operation, an Undo feature is available that restores the last set of LUT values.
