$#Linescan colour and Xray Linescan channel select

When a linescan profile window is on display right click to show popup menu.
The colour of the trace may be selected.

When an X-Ray linescan profile window is on display right click to show popup menu.
The colour of the trace may be selected.
The X-Ray Linescan channel may be selected.
$#Point to point reduced format
For a Point to Point measurement object there are associated two results parameters, the distance and the angle.
These results are displayed in the results panel.
This may be modified as follows
	Select the line between the point to point markers
	Right mouse button click to display pop up menu
	Select Properties - Results

Alternatively double click on the results panel.

With the resulting dialog you may select any combination of the results parameters required.

If no parameters are selected the Point to Point object will display in reduced format.

i.e.	 No labels to identify the object.
	The value only of the distance is displayed near the centre of the dotted line.
$#Relative Stage Movement
The parameters Stage Delta X, Stage Delta Y, Stage Delta Z, Stage Delta T, Stage Delta R, Stage Delta M 
have been added. Setting any of them to a value (positive or negative) will add this delta value to the current axis position
and perform a GoTo for the axis. These parameters may be used in macros.

In addition on the Stage tab of the SEM Control panel are a set of Delta buttons which when pressed will allow entry of the above parameter values.
