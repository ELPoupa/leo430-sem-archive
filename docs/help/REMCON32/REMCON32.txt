$#Data Bits
An RS232 comm port setting which determines how many bits make up a single character.

It is important that the same value is selected within Remcon32 as in the program running on the remote PC.
$#KDial a phone number
Allows a connection to be made to a remote PC via a modem connected to the comms port.

When selected a dialog will appear requesting the phone number to be dialed.

{bmc bm2.wmf}

This function is only available when the comms port is open7HMXZG.

Use of modem communication is likely to require Xon/RTS to be selected in the flow controlFlow_Control settings.

To make the program ready for dialing in from a remote PC, it is necessary to open the comms port which has the modem connected to it.
$#Echo
Controls whether characters returned by the SEM are displayed in the text window.
$#KFlow Control
An RS232 comm port setting which determines how data overrun is prevented.

It is important that the same value is selected within Remcon32 as in the program running on the remote PC.

For remote communications via a modem Xon/RTS is likely to be required.
$#General Description
Remcon32 is a utility program which permits a remote PC to communicate with the SEM using an RS232 protocol.

Details of the RS232 protocol are published by LEO under the OpenX policy. Contact your local LEO representative for further details.

Remcon32 has several advanced features designed to enhance its usefulness, namely :
1.	Remote PC connection via a modem7HBQVE.
2.	Logging a remote control session to a text file4_C4CL
3.	Local mode1UKN0RR operation for testing remote control sequences
4.	Easy configuration of comm port settings1VDW3L3

$#KHang up
Disconnects a remote session via a modem.
$#Keep On Top
Selected to ensure that the Remcon32 window will always be uppermost of the windows on display.
$#KLocal Mode
Allows RS232 commands to be tried locally to the SEM by typing the relevant character sequence in the text window.

This mode is useful for checking that the SEM is responding correctly to RS232 commands and for trying out sequences of commands before coding them into an automated control program.

This mode will normally be used with Echo OnIC2YSC selected.

When this mode is selected no output is sent to the comms port.
$#KOn Startup
Used to determine the actions taken when the program is started.

If the box is checked the comms port will be opened and the program will be minimised, putting it into the ready state to receive external RS232 commands.

If the box is not checked then the port will need to be opened manually.
$#Open Log File
Displays a file selection dialog to allow a filename to be selected so that all RS232 commands and responses can be recorded in a file.

Commands will be logged from when a file is selected until the file is closed1IQ5_DN
$#KOpen Port
Initialises the RS232 port ready for communications.
$#Parity
An RS232 comm port setting which determines how error checking is performed on the data.

The default value for this setting is None.

It is important that the same value is selected within Remcon32 as in the program running on the remote PC.
$#KProperties
This collection of comms properties are used for diagnostic purposes and their settings should not be changed.
$#Stop Bits
An RS232 comm port setting which determines how many bits are used to terminate a transmission.

It is important that the same value is selected within Remcon32 as in the program running on the remote PC.

$#Transmit text file
Allows a file on disk to be transmitted to the remote PC via the RS232 connection.

When activated a standard file selection dialog allows the relevant file to be selected.

This function is only enabled when the comms port is open7HMXZG.
$#Multiple Instances of RemCon32
If you wish to use multiple instances of RemCon32 it is necessary to identify which settings apply to which instance of RemCon32.
This is achieved by adding a command line argument (alphanumeric characters only) which identifies the group of settings to be used.

e.g. ..\leo\leo32\RemCon32.exe EDX

The identifier is displayed in the RemCon32 Caption
