$#Overview
The Stage Administrator is a utility for creating, editing and selecting new stage types.
The Leo-32 database contains the definitions of existing stage types. These definitions may be used as the basis to create new stage types.

Access to the Stage Administator is controlled by Logon and is restricted as follows:

Development
{bmc bm0.bmp}	Unrestricted access, but may not edit predefined stage types.

Users with Supervisor privilege
{bmc bm0.bmp}	May inspect data

Users with Calibration Privilege
{bmc bm0.bmp}	May inspect data
{bmc bm0.bmp}	May select alternative, already created, stage types as the custom stage type.
{bmc bm0.bmp}	May be granted, for a limited duration, ability to create/edit new stage types. See Keycode accessKeycode_access

Other Users
{bmc bm0.bmp}	No access


$#Keycode access
A User with Calibration privilege may be granted the ability to create and edit stage data by means of a KeyCode.

A KeyCode is a unique, date sensitive, serial number specific code which is granted to an engineer by the LEO Engineering Department. 

To enter the KeyCode select the menu item Edit - Enter KeyCode.
In the dialog enter the Keycode, the number of days duration and select OK.

Following successful entry of the keyCode editing rights are granted for the duration defined.
On subsequent logons on to the Stage Administrator you will be reminded of the unexpired days or notified if the period has expired.

$#Power Down stage attributeStage_Attributes.

This attribute describes the behaviour of the stage motors when they become idle.

This attribute will only take effect if supported by the version of stage firmware fitted.

Earlier versions of firmware not supporting this function operate with LowMag 1/4: HighMag 1/2

The transition point for LowMag:HighMag is 50 nanometres per pixel

Choices are:
{bmc bm0.bmp}	1/4 power (the default operation)
{bmc bm0.bmp}	1/2 power
{bmc bm0.bmp}	LowMag 1/4 power, HighMag 1/4 power
{bmc bm0.bmp}	LowMag 1/4 power, HighMag 1/2 power
$#SnapBack stage attributeStage_Attributes

SnapBack is where, on completion of each move, the motor is moved back 3 microsteps to minimise drift.

If attribute is checked this function is implemented.

Note that the ability to turn this function off  may not be supported by the version of firmware fitted.

Earlier versions of firmware always have this function selected.

$#Initialisation Order
This axis attributeAxis_attributes is displayed for each axis in the main window.

The attribute is the numeric order in which the axes are initialised.
$#Protected Z Priority
This axis attributeAxis_attributes is displayed for each axis in the main window.

The attribute is the priority used to define the order of moves when protected Z mode is switched on.

The priority is a number in the range 1 through 3.

When performing a protected Z move the action is:
{bmc bm0.bmp}	Move down all axes with priority 1 if applicable.
{bmc bm0.bmp}	Move down all axes with priority 2 if applicable.
{bmc bm0.bmp}	Move all axes with priority 3 if applicable.
{bmc bm0.bmp}	Move up all axes with priority 2 if applicable.
{bmc bm0.bmp}	Move up all axes with priority 1 if applicable.

$#Range Override
The high limit of travel for an axis may need to be modified when the stage is fitted to a particular configuration.

This is achieved using the Range Conditions button on the axis data window.
This botton displays the Range Conditions window in which rules may be defined to determine the axis high limit.

Rules may be based either on a column type or a machine type.

The rule also takes into account whether a WDX is fitted or not.

To Add a rule
{bmc bm0.bmp}	If no rules are currently defined, select column or machine
{bmc bm0.bmp}	From the appropriate drop down box select the column type or machine type
{bmc bm0.bmp}	Uncheck the WDX box 
{bmc bm0.bmp}	Enter the range value which applies under these conditions
{bmc bm0.bmp}	Select Add to add this rule
{bmc bm0.bmp}	Check the WDX box
{bmc bm0.bmp}	Enter the range value which applies under these conditions
{bmc bm0.bmp}	Select Add to add the rule

When the stage is configured the rules will be scanned in turn to check if they apply, if they do the range value is overriden with the value supplied.

Remove a rule by selecting it and pressing Remove or double click it
Column/Machine selection may only be changed if no rules are defined.

{bmc bm0.bmp}	press OK

If required delete an axisDelete_an_axis
modify the stage attributesStage_Attributes as required

Note that until changes are applied or discarded the selected stage type may not be changed.
