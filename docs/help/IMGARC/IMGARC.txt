$#KIntroduction

The LEO FTP Image Archive Utility (ImgArc) is designed to allow the SEM Operator to transfer a copy of saved SEM Image FilesSEM_Image_Files to a remote computer using FTP; the TCP/IP Internet protocol for file transfer.

This application program assumes that the TCP/IP protocol is installed and correctly configured on the system that you are running the application on, and on your target system. Your local system administrator should be able to help you configure your computer(s) to use this protocol..

The remote or host computer must be capable of receiving FTP commands, and should be configured as an FTP server. There is additional support for network printers that accept commands and images using the FTP protocol. Such an example is the Codonics NP1600 printer.

The user configures ImgArc by providing the internet address of a host computer, along with username, password and target directory that describe where the image files are to be stored.

A basic interface exists for the user setting up ImgArc to verify that these parameters have been set correctly prior to transferring their image files.

When this application is invoked from the SEM user Interface, only those image files with their archive attribute1MP7OUG set will be copied. The archive bit is cleared only when the image has successfully been copied to the host computer.

Finally, the user can also specifiy whether files are copied as they are saved, or at the end of a 'session' on the SEM.

$#KScaling Selection

This option is for use with Network Printers and is located on the Network Printers TabNetwork_Printer_Tab, and is activated when the Enable Network PrinterEnable_transfers_to_Network_Printer option is checked.

This option sets the method by which images are scaled down and pixels removed to allow an Image to be fitted into its position on the printed page. The current methods available for scaling Images are any of :

{bmc bm0.bmp}	BOX : Box scaling is the fastest of the scaling algorithms. It is implemented using pixel replication. Box should be used for images containing text with block letters in which text must remain sharp. Artifacts : Box tends to produce blocky-looking prints, especially when large scale factors are used.
{bmc bm0.bmp}	BILINEAR : Bilinear scaling is the second-fastest scaling routine and is the default printer setting. It employs a linear interpolation to determine the output image. Bilinear scaling provides ver good scaling for most applications where scale factors are relatively small (4X or less). A great amount of optimization effort was put into the bilinear algorithm. Artifacts : Block letters will have fuzzy edges. Bilinear results in a slight decrease in dynamic range for large scale factors.
{bmc bm0.bmp}	BICUBIC : The Bicubic algorithm produces the smoothest output, but tends to smooth over fine details. The filter function is a cubic B-spline filter. This routine requires the same processing time as Mitchell. Bicubic is recommended for applications where the smoothest output is required. Artifacts : Images may appear somewhat blurry due to the smoothing of the filter. Block letters will have fuzzy edges.
{bmc bm0.bmp}	MITCHELL : Mitchell uses a cubic Mitchell function to produce a very smooth output while maintaining dynamic range and sharpness. Mitchell processing takes approximately twice the processing time as Bilinear. Mitchell can be used for any scaling application, especially when scaling factors are 2X or greater. Artifacts : Block letters will have fuzzy edges.
{bmc bm0.bmp}	LANCZOS : Lanczos uses a filter based on the sinc function. This is the most theoretically correct filter and produces the best output for photographic images that do not have sharp transitions in them. However, Lanczos will produce ripple artefacts especially for block text, due to aliasing. Lanczos also requires three times the processing time of Bilinear. Lanczos is not recommended except in very rare applications using band-limited photographic images with no sharp edges. Artifacts : Lanczos produces ripple artifacts around sharp edges, such as found with text. This algorithm is not recommended for most applications.

This option is actioned when the Apply Print SettingsApply_Print_Settings Button is Pressed.
