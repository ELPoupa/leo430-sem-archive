$#Overview
The trackerball option provides an alternative method of adjustment of some parameters to provide a 'two handed' operation of the SEM

The trackerball comprises a ball which may be moved in two dimensions to control one or two parameters. The parameter adjustment is non linear, spinning the ball results in accelerated adjustment.

The trackerball also has three buttons, pressing each button selects predefined parameters for adjustment.

The current parameters being controlled are displayed in the Trackerball ToolbarTrackerball_Toolbar 


See also InstallationInstallation
$#KInstallation
On installation of the trackerball it is essential to define the Serial Port to be used for the trackerball, this is done in the Administrator - configuration form.

The Trackerball toolbar is displayed by selecting View - Toolbars and checking the TKB checkbox.

Unless the Port is defined, is successfully configured, and the Trackerball licence is present the TKB checkbox will not appear or will not be enabled.
