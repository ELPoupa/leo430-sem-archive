$#>Annotation File Types (.ANN, .ADZ)

Annotation ObjectsObject_Selection that can be saved is stored in .ANN files along with their respective propertiesObject_Properties  (some objects such as the reduced rasterReduced_Raster_Object box cannot be saved as annotation). This may be useful if a specific overlay is required to load on top of an image in the SEM Image Store, or if a frequently used set of measurement objects needs to be created more easily.

The reason for the Annotation having two file extensions is that if the user wishes to load in a special user defined DataZoneData_Zone, then the definition for the DataZone is saved as an .ADZ file. If the file is saved as CURRENT.ADZ in the User Directory, then when the DataZone is displayed from the SEM User Interface this annotation file is loaded. The internal formats of the .ADZ and .ANN files are otherwise identical.

Note : As this file is automatically saved when any changes are made to the current DataZone, do not copy a user defined DataZone over CURRENT.ADZ while the SEM User Interface is loaded. This is because at the next DataZone change, CURRENT.ADZ will be overwritten with whatever is currently in memory, overwriting any CURRENT.ADZ file already present on disk.

$#Annotation Warning
{bmc bm3.bmp}  WARNING CONCERNING ANNOTATION

If it is required to save an image into a TIFF file and later to load and print it to hardcopy then do not include the magnification value when saving to file.
If the annotation (e.g. data zone) is merged into the image and saved to a TIFF file then the magnification will be that with reference to the display device. If the file is subsequently reloaded and printed then the magnification VALUE will not be correct for this media.

NOTE: The facility is provided to fix the output magnification to be referenced to a Polaroid 54532AVUYD@leoserv.hlp

For unambiguous magnification use a Micron MarkerMicron_Marker.


However, the file will contain the pixel sizes for each zone on the reloaded image so that the correct magnification can be re-established using Zone MagnificationZone_Magnification.

For measurement on imported TIFF files also observe Measurement WarningMeasurement_Warning.

$#>Co-ordinate System

Although the store resolution of the SEM Image can be greater or less than the viewport area, Image Manager always works over a 1024x768 display area. 

This is an important point, as all cartesian co-ordinates used by Image Manager are also in these display units.

The top left co-ordinate (0,0) represents the origin of the display. 

The bottom right limit of the display area is therefore at co-ordinate (1023, 767).

$#>Data Zone

The data zone is a special group of annotation objects which are used to display current parameters, including if required a micron marker showing the base magnification. The data zone objects are disconnected from the normal annotation objects (e.g. reset does not remove them) and they are switched on/off using the top menu function from Menu View6Y3XP3@Sem.HLP.

{bmc bm42.bmp}

The user may edit the data zone by using the technique of Sticky Panel AnnotationSticky_Panel_Annotation .

Modifications to the Data Zone, for example the addition of SEM Parameter ObjectsSEM_Parameter_Object, will be saved automatically.

When a Data Zone is subsequently recalled it is loaded from a CURRENT.ADZAnnotation_File_Types file in the users directory.

Note : As this file is automatically saved when any changes are made to the current DataZone, do not copy a user defined DataZone over CURRENT.ADZ while the SEM User Interface is loaded. $#JPEG

(pronounced "jay-peg") is a standardized compression method for full-color
and gray-scale images.  JPEG is designed to handle "real-world" scenes,
for example scanned photographs. 

JPEG is lossy, meaning that the output image is not necessarily identical to
the input image.  Hence you should not use JPEG if you have to have identical
output bits.  However, on typical real-world images, very good compression
levels can be obtained with no visible change, and amazingly high compression
is possible if you can tolerate a low-quality image.  You can trade off image
quality against file size by adjusting the compressor's "qualityJPEG_Quality" setting.
$#JPEG Quality
The quality switch lets you trade off compressed file size against quality of
the reconstructed image: the higher the quality setting, the larger the JPEG
file, and the closer the output image will be to the original input.  Normally
you want to use the lowest quality setting (smallest file) that decompresses
into something visually indistinguishable from the original image.  For this
purpose the quality setting should be between 50 and 95; the default of 75 is
often about right.  If you see defects at quality 75, then go up 5 or 10
counts at a time until you are happy with the output image.  (The optimal
setting will vary from one image to another.)

In the other direction, quality values below 50 will produce very small files
of low image quality.  Settings around 5 to 10 might be useful in preparing an
index of a large image library, for example.

$#Measurement Warning
{bmc bm3.bmp}	WARNING CONCERNING MEASUREMENT 

If a TIFF image is imported which is less than full size (due to spatial reduction or saving only part of an image) then there is no constraint on where the image is loaded in relation to the scanned image. 
The determination of which zone applies to which portion of the image is governed by the position within the scanned image, and this information is used in measurement. 
It therefore follows that if a portion of image which was in Zone 0Zone when saved is inserted into a position in the scanned image corresponding to zone 1 and zones 0 and 1 have different pixel sizes then any measurement performed will be incorrect.

$#Software Principles

The LEO-32 Image Manager which handles Annotation and Measurement is a special application that co-exists with the SEM User Interface (SEM UIF). It acts as an overlay on top of the SEM Image, and allows various image related functions to be actioned easily. Typical functions would be those that add image annotation and measurement objects, save images, change SEM operating modes etc.

Unlike most windows applications, when the SEM UIF window is moved, the image portion or 'Client Area' to use Window terminology; remains static along with the overlay provided by Image Manager. The SEM UIF Client Area and Image Manager overlay can in this way be seen as a viewport on the Image.

The Image Manager is controlled mainly by a simple 'selection and execution' process using the mouse. The user 'selects' a toolbar or menu function and 'executes' its features by clicking and dragging the mouse over the desired area of the viewport. Where possible, some additional keyboard short-cuts have also been implemented for use with Image Manager.
As Image Manager is object oriented, all of its functions can be classed or sub-classed into Image Manager Objects. An object can be anything from a measurement tool, to a piece of text, to a file selection area.

Finally, Image Manager works with a standard co-ordinate systemCo_ordinate_System and  a standard measurement systemStandard_Measurement_System that is applied to all objects.

The Image Manager, where possible, is logically partitioned into a number of discrete sections, each having one of two goals : -To select a specific function or action. -To apply a specific action in the context of the selected function. Selection of functions can be achieved by making selections from  :

The Annotation ToolbarCalling_the_Annotation_Toolbar, the SEM Menu Bar8ZP0K4@Sem.HLP and the Image Manager Context Sensitive Popup MenuContext_Sensitive_Popup_Menu.

The contents of the Popup Menu are determined by the current operating modeImage_Manager_Operating_Mode of the Image Manager. Wherever possible, help text is displayed in the SEM UIF Status Bar Message AreaStatus_Bar_Message_Area. Objects can easily be createdCreation_of_Objects or selectedObject_Selection by using the Annotation Toolbar functions.

This function requested from the Pop up MenuContext_Sensitive_Popup_Menu selects Video Printer as Output Device.
The Software does not initiate the printing, as this device is not controlled from the software, however it does select the output device calibration as previously calibrated for this device.
